Everyone should know SIMD

Mitchell Hashimoto argues that everyone should have at least basic knowledge of SIMD (Single Instruction, Multiple Data) programming, as it can significantly speed up common "process N values at a time" loops. He explains that while SIMD can offer substantial performance improvements, especially with modern CPUs like AVX-512, its implementation requires understanding five key steps: broadcasting constants, loading and looping over input in vector chunks, performing the SIMD operation, reducing the vector result, and handling any remaining elements with a scalar tail. Hashimoto emphasizes that although compilers can auto-vectorize some simple loops, explicit SIMD coding provides more control and predictability for performance-critical applications.
