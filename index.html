You could have invented transformers from memory

The article explains how large language models store and recall information using different memory architectures, focusing on the outer-product memory store, the optimal linear memory store, and the multi-layer perceptron (MLP) as a nonlinear memory store. It demonstrates that while the outer-product store can store up to \(d_k\) memories before interference becomes significant, the optimal linear store can store twice as many. Claude reveals ECDSA curve origins

Claude, an employee at Anthropic, uncovered the origins of the seeds used to generate widely-used elliptic curve cryptography (ECDSA) standards, revealing they were generated by a simple Unix timestamp-based pseudorandom number generator (PRNG) rather than a cryptographic hash function.
