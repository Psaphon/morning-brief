A security vulnerability was discovered in Python's implementation of IDNA 2003, where the use of `str.lower()` to handle Unicode case folding can lead to inconsistent behavior due to differences between the Unicode version used by the Python interpreter and the required Unicode 3.2.0 version specified in RFC 3454. This inconsistency can result in incorrect domain name encoding, potentially compromising security. The vulnerability was addressed by creating new exceptions to ensure `str.lower()` behaves consistently with Unicode 3.2.0, as detailed in CVE-2026-17084. Key contributors include the Security Developer-in-Residence at the Python Software Foundation and other reviewers.

Queryable Executables

Queryable Executables, or SELF, present an innovative format where programs are stored as SQLite databases, allowing applications to store their state within the same file. This approach simplifies deployment and management by collapsing a program's code, data, and state into a single file, leveraging SQL for both execution and state persistence. Key actors include the author of the article and Justine Tunney, whose prior work inspired this idea.
