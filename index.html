Surelock: Deadlock-Free Mutexes for Rust

Surelock is a Rust library designed to prevent deadlocks by ensuring that lock acquisitions are either proven safe at compile time or rejected entirely. It uses two mechanisms—LockSet for atomic multi-lock acquisition and Levels for incremental locking with compile-time ordering enforcement—to break the circular wait condition, which is one of Coffman's four necessary conditions for deadlock. The library aims to provide a safer way to use mutexes in Rust while maintaining minimal ceremony and no runtime dependencies.
